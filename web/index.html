What Cited adds to Claude

Claude can already search the web. Cited does something different: it searches the source itself, and tells you how well the source actually covers your question.

🗂️

Searches the archive, not the web

Up to 200 recent posts per newsletter, searched by meaning — including older posts web search ranks poorly.

❝

Quotes you can verify

Every claim comes with the exact passage, post title, date, and a link to read it yourself.

🎯

Honest confidence

High, Moderate, or Limited coverage on every answer. When the source doesn't cover it, Cited says so — plainly.

Add Cited to Claude

Takes about a minute. No account, no API key.

claude.ai (web, desktop, mobile)

  1. Open Customize → Connectors and click + Add → Add custom connector.
  2. Name it Cited and paste this URL:
    https://cited-7bys.onrender.com/mcp
  3. Choose No sign in, click Add, then turn Cited on from the + menu in a chat.

Claude Code

  1. Add the plugin marketplace:
    claude plugin marketplace add drLIyer/Cited
  2. Install the plugin:
    claude plugin install cited@cited-plugins

Questions

Is it free?

Yes. Cited runs the search; Claude writes the answer using your own Claude plan. There's a fair-use limit of 15 searches per minute.

What does Cited see?

Only what Claude sends in a search — the newsletter URL and the search question — never the rest of your conversation. See the privacy policy.

Does it read paywalled posts?

No. Cited only searches public posts. If a newsletter is mostly paywalled, Cited will tell you it found little.

How far back does it go?

For Substack, up to the 200 most recent public posts. RSS and podcast feeds include whatever the feed lists — often the latest 10–50 items.

What do the confidence levels mean?

They measure how closely the best passages match your question. High: strong matches across several posts. Moderate: at least one good match. Limited: the newsletter barely covers it — Claude says so and flags anything from general knowledge.

Does Cited respect writers who don't want their work used by AI?

Yes. Before reading any site, Cited checks the writer's AI opt-out signals (robots.txt rules for AI crawlers, "noai" tags, and the TDM reservation standard). If a writer has opted out, Cited doesn't fetch or index their work — and deletes anything it had stored.

Is it open source?

Yes, MIT-licensed, on GitHub.
